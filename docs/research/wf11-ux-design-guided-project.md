# Content Machine 1.0: coach experience design ("Guided Project", EN + VN)

## 0. The design in 8 lines
1. **One Project kit, the same in ChatGPT and Claude.** On a computer: create a Project, paste ONE instruction block, add 2 files, type "Start". About 3 minutes. Both apps get the same block, the same files and the same words.
2. **The machine is the installer.** After the first message, every later setup step is offered inside the chat, one step at a time, only when it is needed. That covers saving the brand, reminders, automations, the board, the Grow file and Claude full-auto.
3. **Phone door.** A coach without a computer pastes one starter prompt (30 s) and gets the same first session up to the first script. "Make it permanent" happens later, guided, in about 3 minutes on a computer.
4. **One decision per session.** In session 1 it is "OK" on the Message Map. The reward for saving MY BRAND is the first script, so the save step reliably happens.
5. **Memory is one MY BRAND source** inside the Project, saved with the app's own button and refreshed at most once a month. App memory is only a soft backup.
6. **The weekly recording becomes a "Weekly Talk".** The coach answers the machine's questions by dictation for about 25 minutes while the phone films. The transcript is the chat, so there is no export or paste step.
7. **Automations come after the first full week. The board comes when a trigger happens.** Neither is needed for good results; "What's next?" always works.
8. **The VN edition defaults to ChatGPT.** Vietnamese dictation works there, Free text use is unlimited, and no international card is needed.

## 1. Install

### 1.1 Setup page: two questions, then 4 steps
The founder hosts one page per edition: EN "Start here", VN "BẮT ĐẦU TẠI ĐÂY". A Notion public page is enough, because its code blocks have copy buttons and attachments can be downloaded.
- Q1: "Which app do you use?" **[ChatGPT]** **[Claude]**. On the VN page ChatGPT is marked "Khuyên dùng" (recommended).
- Q2: "Are you at a computer now?" **[Yes → Door A, 3 min]** **[No, only my phone → Door B, 30 s]**
- At the top: a sample Message Map (Dana or chị Hạnh) plus a film-today script, labelled "what you'll have in 40 minutes". The coach sees the outcome before doing any work.

### 1.2 Door A: computer, any plan (the recommended path)

| Step | ChatGPT (chatgpt.com in a browser, or the Windows app; **on a Mac, use the browser, not the Mac app**) | Claude (claude.ai or the desktop app) | Time |
|---|---|---|---|
| 1 | Left sidebar → **Projects → New project** → name "Content Machine" → keep memory on Default → **Create** | Sidebar → **Projects → + New project** → "Content Machine" → **Create** | 30 s |
| 2 | **Instructions** → paste (**button A** on the setup page) → **Save** | **Set project instructions** → paste (button A) → **Save** | 45 s |
| 3 | **Add files** (or Sources → Add) → select **both** files (button B) at once → wait for the ticks | **Project knowledge "+" → Upload from device** → select both files | 45 s |
| 4 | In the project's chat box: **Start** | Same | 10 s |
| | **About 2–3 min** | **About 3 min** | |

VN setup-page copy, ChatGPT version. The EN UI labels stay in brackets because many VN users run ChatGPT in English:
1. Mở chatgpt.com trên máy tính → thanh bên trái → **Dự án (Projects) → Dự án mới (New project)** → đặt tên "Content Machine" → **Tạo**.
2. Bấm **Hướng dẫn (Instructions)** → dán (nút A) → **Lưu**.
3. Bấm **Thêm tệp (Add files)** → chọn **cả 2 file** vừa tải (nút B) → chờ dấu tích.
4. Trong ô chat của dự án, gõ: **Bắt đầu**

Two things to note:
- The VN ChatGPT labels have not been checked. The 90-second video per app is the primary guide, and the text steps are the backup.
- Tip printed on the page: "You can do the talking part on your phone. Open the same project in the app; it is the same chat."

### 1.3 Door B: phone only (30 s, the weaker path)
1. Setup page → **Copy starter** (≤8,000 characters: a compact instruction block plus the first-session method).
2. Open the ChatGPT or Claude app → new chat → paste → send.

The session runs the same way up to the first script and the MY BRAND output (§2.4). It ends with: "This becomes permanent in 3 minutes on a computer. Want a reminder for tonight?"

**Move-in later.** The coach does Door A steps 1–3, then types **Start** and pastes MY BRAND in the same message. The machine recognises it, prints a clean save-file, and the coach saves it. This works in both apps and does not depend on a "Move chat to project" feature, which is unverified.

If Phase 0 shows that Projects can be created on phones, the page drops the computer requirement and Door B becomes rare.

### 1.6 What can fail, and the fix inside the chat
The instruction block runs a self-check at the start of every chat. Most failures are therefore caught by the machine itself, and it never refuses to start.

| Failure | How it shows | Fix in the chat (EN / VN) |
|---|---|---|
| Method files missing or not uploaded | No `§CM` anchors found | **Compact mode**: session 1 still runs from the block. "I can't see my 2 method files yet. We can start anyway; I'll ask you to add them at the end (1 min)." / "Mình chưa thấy 2 file phương pháp. Mình vẫn bắt đầu được, cuối buổi mình chỉ bạn thêm vào (1 phút)." |
| Block pasted into the chat, not into Instructions | The block appears as a user message | "Looks like you pasted my setup text into the chat. It works for today. To make it permanent (1 min): open the project → Instructions → paste → Save." / "Hình như bạn dán phần cài đặt vào ô chat. Hôm nay vẫn chạy được. Để dùng lâu dài: mở dự án → Hướng dẫn (Instructions) → dán → Lưu." |
| Files attached to a message instead of the project | Files visible only in this chat | One-line instruction to add them to the project instead |
| A `.md` file opens as text instead of downloading | Setup page | "Press Ctrl+S / Cmd+S", or use the **Copy text** button and add it as a text source |
| ChatGPT Free daily upload cap reached | Upload error | Compact mode today; "add the files tomorrow" goes into the NEXT line |
| Trying to create the Project on a phone | No "New project" option | "This step needs a computer (3 min). Want a reminder tonight?" / "Bước này cần máy tính (3 phút). Bạn muốn mình nhắc tối nay không?" |
| Mac ChatGPT app can't create projects | Same | "Use chatgpt.com in Safari or Chrome" |
| MY BRAND not saved | Self-check in a later chat | "I can't find your MY BRAND. Open your first Content Machine chat, find the message starting 'MY BRAND', tap ⋯ → Save to project, then say 'saved'." / "Mình chưa thấy MY BRAND. Mở đoạn chat đầu tiên, tìm tin nhắn bắt đầu bằng 'MY BRAND', bấm ⋯ → Lưu vào dự án, rồi gõ 'đã lưu'." |
| Two or more MY BRAND versions saved | Self-check | Use the highest version, then one line: "When you have a minute, remove v2 from the project files." / "Khi rảnh, xoá bản v2 trong mục tệp của dự án nhé." |
| Chatting outside the Project | **No "▸ Content Machine" tag** at the top of the reply | Taught in the first 3 NEXT lines and in every reminder: "Always open the project first." This is the one failure the machine cannot detect; the coach has to notice the missing tag. |
| Lost in the app's interface | Coach asks "where?" | "Not sure where to click? Send me a screenshot and I'll point to it." / "Không biết bấm chỗ nào? Chụp màn hình gửi mình, mình chỉ cho." |
| Claude Free cap hit during the interview | App message | Save points after the brain-dump and after the Map. "Come back after {time}, same chat, say 'continue'." |

## 2. First session, minute by minute (Door A, including install)

Every reply starts with a running tag and ends with one NEXT line:
- Tag: `▸ Content Machine · Setup 2/5 · Your message` / `▸ Content Machine · Cài đặt 2/5 · Thông điệp`
- NEXT: `→ NEXT (10 min): …` / `→ TIẾP (10 phút): …`

### 2.1 Timeline

| Min | Coach | Machine |
|---|---|---|
| 0–3 | Install (4 steps) | — |
| 3 | Types "Start" / "Bắt đầu" | Self-check, then the 3-line promise and the brain-dump prompt (Message Focus Engine §1.2). Mic tip: "tap the **small mic**, NOT the sound-wave button" / "bấm **micro nhỏ**, KHÔNG bấm nút sóng âm". For Claude VN: keyboard mic. Other options: paste a live, webinar or podcast transcript, or the last 10 posts. |
| 4–13 | Talks in 2–3 dictated chunks | "Got it. Keep going or say 'done'. You haven't mentioned {jogger}." Without showing it, the machine extracts the inventory, who candidates, client words, stories, proof, moments, the voice card, energy per topic, and **pillar #0 passages**. |
| 13–14 | "done" / "xong" | Inventory (3 lines of reassurance) plus the pre-filled check: the engine's 6 lines **plus line 7**: "How you'll work: {main platform + email/Zalo} · {hours}/week · record {day} · {bullets / word-for-word / questions} · (VN) xưng hô {…}". This folds the old "defaults" turn into the same check. The "?" appears only on 2–3 lines. |
| 14–19 | "ok, fix 4", then answers 2–3 "?" questions by voice | One question per message, at most one probe each. Quick Listen runs after Q2 (≤5 searches; skipped if the app can't browse). The why-chain gives Pillar 1's root cause. |
| 19–21 | — | The **Message Map** (one screen), the "Why this one" line, 2 alternate keywords and the 3-line pocket version: "Screenshot this; it's your whole strategy." |
| **21** | **The one decision: "OK"** (or "change line 3") | — |
| 21–23 | **Taps ⋯ → Save to project**, then says "saved" | **MY BRAND v1** as one message that is only the save-file (§2.2). The reward is announced: "say 'saved' and I'll give you your first script." |
| 23–26 | Reads it, then films now or later | **FILM TODAY** (§2.3). "Prefer to post text today? Say 'text'." |
| 26–32 | Skims; says "next" once or twice | Season 1 in 4 lines (Week n = Pillar n). The CTA kit: the keyword; a free gift **the machine writes**, sized to fit in a DM so nothing has to be hosted; and DM replies 1 and 2 ("copy these into your phone Notes"). The Week-1 film list, dated and cut from the dump, with script #2 in full and the rest on "next". Claude Free gets 3 per reply. |
| 32–34 | — | First **Weekly Talk** date: "you'll just answer my questions for 25 minutes while your phone films." |
| 34–36 | Taps 1–3 calendar links (optional) | Wrap-up: today / record day / Friday in 3 lines; the files step if in compact mode; one NEXT line. |

About 9–12 coach turns, and a film-ready script by about minute 26 including install. "later" / "lát nữa" works at any point after the Map, and "What's next?" resumes from there.

### 2.2 MY BRAND and the save step
**Contents** (≤12 KB EN / ≤15 KB VN):
- META: version, dates, `plan_start`, time zone, tier, mode, xưng hô, app.
- MESSAGE MAP (≤1,200 characters).
- VOICE: 5 verbatim phrases.
- CHARACTER, compact.
- CTA KIT.
- SEASON skeleton.
- MY WORDS: ≤6 passages from the dump, each ≤60 words.
- BANK: the top client words, stories, proof and moments, with IDs.
- SETUP checklist.
- "For the machine (you can ignore this)" / "Phần dành cho máy (không cần đọc)": the Big Domino, B1–B7 and the focus scores.

**First line of the message:** "This is your MY BRAND file; no need to read it. Tap ⋯ under this message → Save to project. Then say 'saved' and I'll give you your first script." / "Đây là file MY BRAND của bạn, không cần đọc. Bấm ⋯ dưới tin nhắn này → Lưu vào dự án (Save to project). Xong gõ 'đã lưu', mình đưa kịch bản đầu tiên liền."

**Fallbacks, in this order. Phase 0 decides which one is the default:**

| # | ChatGPT | Claude |
|---|---|---|
| 1 | ⋯ → **Save to project** / "Add to project sources" [UNVERIFIED on Free and mobile] | MY BRAND is produced as a document → ⋯ → **Add to project** [UNVERIFIED on Free/Pro] |
| 2 | Copy → Project → Sources → Add → **Text** → paste | Copy → Project knowledge **+ → Add text content** → paste [label UNVERIFIED] |
| 3 | Same for both: "Remember: {pocket version}" goes to app memory, and the coach pastes MY BRAND after "Start" next time. | |

### 2.3 The first piece (one phone screen)
- On-screen hook (≤6 words).
- First line, word for word.
- 3 beats.
- Last line, word for word.
- Caption with the keyword.
- CTA.
- `WHY THIS GETS CLIENTS: shifts "{old belief}" → "{new belief}" · next: …` / `VÌ SAO RA KHÁCH: …`
- **A plain check line instead of the coded footer:** "✓ Checked: one idea · sounds like you · uses your 2019 story · keyword 'Quiet Exit' once · no risky claims · next: Part 2 tomorrow" / "✓ Đã kiểm: 1 ý · đúng giọng chị · dùng chuyện spa 2018 · từ khoá 'khách quay lại' 1 lần · không có câu hứa rủi ro · tiếp: Phần 2".

If proof is missing, at most one line: "? Needs you: how many weeks did it take Maria? Say a number or 'skip'."

### 2.4 What the coach walks away with
1. ONE message, plus a 3-line pocket screenshot.
2. A NOT NOW list (≤7 items): "nothing wasted".
3. A short that is filmed, or ready to film today.
4. Week 1: 3–4 dated pieces, all in their own words.
5. The date of the first Weekly Talk.
6. MY BRAND saved, so the machine remembers them.
7. Optional phone reminders.
8. One NEXT line.

They never filled in a template or chose a framework.

**Door B difference:** the session stops after FILM TODAY and the MY BRAND save-file. Season 1 and Week 1 run after move-in, because "Start" sees MY BRAND and resumes from the SETUP checklist.

## 3. Week 1 and the weekly loop

### 3.1 Calendar rule
`plan_start` is this Monday if setup happens on a Monday or Tuesday; otherwise it is next Monday. The days in between are **Week 0**, which holds the film-today piece plus 1–2 pieces from Week 1.

### 3.2 Week 1, day by day (example: setup on a Saturday, record day Tuesday, Lean tier)

| Day | Coach does (min) | Total |
|---|---|---|
| Sat | Setup (36) + film and post today's short (15) | ~50 |
| Sun | Post the text post: copy the caption into Facebook or LinkedIn (3) | 3 |
| Mon | Project → **new chat** → "What's next?" (5) → film short #2 (10) + post (3) | ~18 |
| Tue (record day) | **Weekly Talk #1** (25) + read 5 "re-say lines" to camera (3) + "cut it" → skim the cut kit (5) | ~33 |
| Wed | Post a re-say short or a clip (10). Optional: send the Buyer Mirror message to 3 clients (5); it unlocks real proof for Week 3. | 10–15 |
| Thu | Post the email or Zalo message (3) | 3 |
| Fri | In Monday's chat: "3 numbers + best post" by voice (3) → review (2) → **automations offer** (4, optional) | 5–9 |

### 3.3 The Weekly Talk (replaces "record a pillar, then paste a transcript")
1. Record day: Project → **new chat** → "What's next?". The machine replies: "Phone on a stack of books, camera on, start recording. Then tap the mic on your computer and answer my questions. Ready? Say 'go'."
2. 5–6 questions in belief order for this week's pillar, one per message, each with a "tell me the time when…" prompt. The machine replies with minimal "Got it. Next:" messages.
3. At the end come 5 **re-say lines**: hooks and short passages the coach reads straight to camera.
4. "Stop recording. Say 'cut it'."
5. The cut kit. Each clip has the first and last words of its passage, on-screen text and a caption. It also includes:
   - a **re-say version** of each clip: the same passage as a one-take short, for coaches with no editor;
   - 1 text post or carousel;
   - 1 email or Zalo message;
   - a schedule from Wednesday to the following Tuesday.

Three variants:
- **Coach recorded elsewhere:** "how to get your words out" help appears just in time: YouTube "Show transcript", iPhone Voice Memos, or CapCut captions.
- **Phone-only coach:** the laptop camera films and the phone app dictates.
- **No Talk this week:** a 10-minute mini-talk with 3 questions.

### 3.4 Weekly loop from Week 2 (Lean ≈ 75–90 min a week; Standard adds about 30)

| When | Coach (min) | Arrives by itself: none / ChatGPT tasks / Claude Pro full auto | Copy or paste where |
|---|---|---|---|
| Mon | New chat → "What's next?" → skim the film list and say "ok" (5) | — / 07:07 push: this week's pillar plus the Monday short draft / the week's scripts already in Notion "This Week" | — |
| Mon–Tue | Film short N1 (10) + post (3) | — | Caption → TikTok, Reels or Facebook |
| Record day | Weekly Talk + re-say lines + "cut it" (~35) | — / — / cut rows written to Notion | Nothing (the talk is in the chat) |
| Wed–Tue, 4–5 days | One piece a day: a re-say short (10), a trimmed clip (10), or a text post or email (3) | — / weekdays 06:37: 1 idea, 3 hooks, 1 question / same, plus logged in Notion | Captions → platform; email/Zalo text → email tool or Zalo; DM replies from phone Notes |
| Fri | In Monday's chat: "3 numbers + best post" by voice (3), read the review (2) | — / 15:07 nudge to open the project / review written to Notion | Spoken numbers; screenshots optional (ChatGPT Free has an upload cap) |
| Anytime | "Save this: {story / client quote / idea}" (30 s) | — | — |

**Chat hygiene. The machine says this in its NEXT lines, so the coach never has to learn it:**
- The **Week chat** covers Monday through Friday.
- The **Talk chat** is used on record day.
- The **Month chat** is used for "plan next month".

This keeps chats short, which matters for ChatGPT Free's roughly 27K context and for long-chat drift. MY BRAND carries everything essential from one chat to the next.

**Friday review screen** (no scores or codes; the input is just 3 numbers):
```
▸ Content Machine · Week 2 · Friday
THIS WEEK   6 posts · ~4,200 views · 38 new followers
HANDS UP    6 said "EXIT" or messaged you · 2 booked a call
YOUR MESSAGE  6/6 on your map · you said "Quiet Exit" 9× · people said it back 2×
BEST        "Not burnout. A dead end." → next week: Part 2 + a new hook
FIX         the "3 steps" carousel → new first slide (below)
NEXT WEEK   Pillar 2 "Test before you jump" · Talk on Tuesday
OPTIONAL (5 min) send this to 3 clients → unlocks real proof for Week 3
→ NEXT: Monday, new chat in this project: "What's next?"
```
The VN labels come from `strings/vn.toml`, for example TUẦN NÀY, GIƠ TAY, THÔNG ĐIỆP, BÀI TỐT NHẤT, SỬA, TUẦN SAU and TIẾP.

**Trade-off:** without a board, the review compares this week's posts with each other. The "2× trailing median" rule only applies once a board exists (L5).

**Monthly.** The Week-4 review ends with "NEXT: Monday, new chat: 'Plan next month' (20 min)". The session:
1. runs the Message check, which defaults to KEEP and is the session's one decision;
2. builds Season 2;
3. produces **MY BRAND v2**: save it and remove v1 (2 taps);
4. regenerates the task texts only if the Map, keyword or offer changed.

**On ChatGPT, automations bring things *to* the coach. Thinking that needs the coach's history stays in the Project.** This is deliberate:
- Tasks can't read Project files, and each run is a separate chat, so a task's review would lose the week's context.
- That is why the Friday task is only a nudge to open the project.
- The daily drop ends with: "Like it? In your project: 'Save this: …'"
- The Monday draft is a short the coach can film straight away. If the coach says they already have it, the project doesn't write another.

**Why automations and the board stay optional:**
- "What's next?" does every job on demand.
- ChatGPT tasks can pause silently when ignored, so the Friday review asks "did your morning messages arrive?"
- Automations that arrive before the coach understands the loop get ignored and then auto-pause. Offering them after week 1 fixes this.
- On ChatGPT, a board means manual pasting. A solo coach without a VA gets the same results from weekly chats.

**Founder decision.** For the VN edition on ChatGPT, offer Sheets Lite first. Notion's interface isn't in Vietnamese [UNVERIFIED], and VN small-business owners know Google Sheets better.

## 5. Phrases the coach ever needs

| # | EN | VN | When |

## 7. Biggest risks for a non-technical 45-year-old

| # | Risk | Mitigation built into this design |
|---|---|---|
| 1 | **Chatting outside the Project.** Plain ChatGPT answers and quality silently drops. | Running tag on every reply; "always open the project first" in the first 3 NEXT lines and in every reminder; reminders name the path ("Projects → Content Machine"). |
| 2 | **The save step fails.** The button is missing, the source is not saved, or there are duplicates. | Save comes before the first script (reward); 3 fallbacks; self-check every chat; recovery is always possible because the MY BRAND message still exists in chat 1. |
| 3 | **Install abandoned at the file step.** File picker or Downloads folder confusion. | Compact mode means session 1 runs anyway; files are requested at the end; "copy text" alternative; 60-s video. |
| 4 | **Tapping voice mode instead of the dictation mic.** The AI talks back and interrupts the dump. | Explicit tip in the brain-dump prompt (EN/VN). |
| 5 | **Claude VN dictation doesn't exist.** | VN defaults to ChatGPT; keyboard-mic instruction on Claude. |
| 6 | **Walls of text on a phone.** | One screen per reply; film list + one script; "next" for more (batched on Claude Free). |
| 7 | **Fear of the camera, or never editing clips.** | Weekly Talk feels like a conversation; re-say shorts need no editing; a "text today" option; the mini-talk means never a zero week. |
| 8 | **Weekly time creep, then drop-off in weeks 2–3.** | Realistic 75–90-minute Lean budget; a 3-number Friday input; "skip the missed post, post the best one today", never guilt; the Friday review rewards progress. |
| 9 | **UI labels change; guides go stale.** | Dated videos re-shot quarterly; "send me a screenshot and I'll point"; the machine describes positions ("the ⋯ under my message") as well as labels. |
| 10 | **Usage caps or context loss** (Claude Free messages; ChatGPT Free about 27K context). | Lean files (≤90 KB); ~12-turn session with save points; one chat per job set by NEXT lines. |
| 11 | **Shared accounts, common in VN, and client privacy.** | The setup page recommends their own account; project-only memory option; client words stored by role only; "remove names before pasting". |
| 12 | **ChatGPT tasks pause silently.** | The Friday check; nothing depends on tasks. |
| 13 | **The message lock feels restrictive** ("I want to talk about X"). | Drift handler bridges or parks without lecturing; 1 off-map piece in 10 allowed on request. |
| 14 | **Expectation mismatch** ("I thought it posts for me"). | The setup page has "what it does / doesn't do" in 3 lines; honest labels per app. |
