# One entry per line; lines starting with "#" are comments.
# A plain entry matches as a whole word or phrase, any letter case.
# "re:" starts a Python regular expression; it is case-sensitive unless it
# begins with (?i). Capitalised regexes below spare ordinary words
# ("a credible offer", "a buying signal").
# To allow one line, end it with <!-- lint-ok:E140 -->; for a recurring value,
# add it to tools/lint_allow.toml [E140].
